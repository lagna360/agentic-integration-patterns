# Security policy

## Scope

This repository contains companion teaching code only. It does not distribute the book. It is not a supported production service, security product, deployed agent runtime, or certification of the example controls. A supported first-edition source state, if designated, will be identified by an immutable commit or a companion-specific tag rather than by attaching book files to this repository.

## Reporting

Do not post credentials, private data, unpublished vulnerabilities, or exploit details in a public issue.

Use GitHub Private Vulnerability Reporting from the repository's **Security** tab when it is enabled. Enabling and testing that channel is a release-time verification item. Until a confidential channel is visibly available, withhold sensitive details; a minimal public issue may ask the maintainer to enable a secure reporting route without describing the vulnerability.

Ordinary documentation mistakes and non-sensitive defects may be reported through GitHub Issues.

## Expectations

The maintainer will distinguish a defect in the teaching example from a production-security advisory. Examples deliberately omit production identity, secret management, broker ACL, network, storage, audit, retention, and deployment controls; consult the book's stated limitations before treating an omission as a vulnerability.
